# C++ 项目合集

## 项目一：RPG角色管理系统

**技术栈：C++**

一个控制台 RPG 角色管理程序，支持角色创建、战斗模拟、数据持久化。

### 核心功能
- 角色创建：支持战士、法师、弓箭手三种职业
- 战斗模拟：随机回合制战斗，不同职业有不同攻击行为
- 多态实现：基类 `Character` + 派生类 `Warrior` / `Mage` / `Archer`
- 数据存储：使用 `map<string, Character*>` 存储角色，按名字快速查找
- 排序：使用 `sort` + Lambda 按攻击力排序
- 文件持久化：使用 `fstream` 保存/加载角色数据

### 技术点
- 继承与多态（虚函数、纯虚函数）
- STL 容器（map、vector、set）
- Lambda 表达式
- 文件读写（fstream）
- 动态内存管理（new / delete）
- dynamic_cast 类型判断

## 项目二：学生成绩管理系统

**技术栈：C++**

控制台学生成绩管理程序，支持信息录入、排名计算、统计与删除。

### 核心功能
- 录入学生信息（姓名、学号、各科成绩）
- 查看所有学生
- 按总分排名
- 按姓名查询学生
- 统计各科平均分、最高分、最低分
- 按姓名删除学生

### 技术点
- struct 定义数据结构
- vector 动态存储
- sort + 自定义比较函数
- 累加与打擂台算法

## 项目三：猜数字游戏终极版

**技术栈：C++**

带难度选择、统计和排行榜的猜数字游戏。

### 核心功能
- 三种难度（简单/普通/困难）
- 随机数生成
- 猜中次数统计
- 排行榜记录
- 游戏统计（总局数、总尝试次数、胜率）

### 技术点
- 随机数生成（srand / rand）
- 循环与分支控制
- struct 定义统计与记录
- vector 存储排行榜
